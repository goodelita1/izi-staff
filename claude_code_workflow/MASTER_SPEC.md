# Project

Local Inventory Management System.

The application is designed for local inventory accounting using SQLite.

The system is intended for a single local workstation.

No cloud services.

No authentication.

No internet connection required.

---

# Goal

Create a production-quality inventory management system with:

- Fast local performance
- Modern UI
- Reliable SQLite database
- QR inventory support
- Excel import/export
- Automatic backups
- Clean architecture
